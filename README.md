# IP Store

Projeto demonstrativo de catálogo digital desenvolvido para a IP Store, com autorização do proprietário, como proposta de apresentação dos produtos e da identidade da loja.

## Sobre o projeto

A proposta do projeto é apresentar uma experiência moderna e responsiva para uma loja que trabalha principalmente com iPhones e outros produtos de tecnologia, além de perfumes, acessórios e moda.

O site funciona como um catálogo digital, permitindo que o visitante conheça os produtos e entre em contato com a loja pelo WhatsApp para confirmar disponibilidade, condições e realizar o atendimento.

## Funcionalidades

- Catálogo de produtos
- Destaque para iPhones
- Seções de tecnologia, perfumes, acessórios e moda
- Página com informações sobre a loja
- Informações de localização
- Integração com Google Maps
- Botões de contato
- Layout responsivo para celular, tablet e computador
- Navegação entre as principais seções do catálogo

## Tecnologias utilizadas

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- Git e GitHub

## Objetivo

Este projeto foi desenvolvido como prática de desenvolvimento front-end e também como proposta de catálogo digital para um comércio local.

A estrutura foi pensada para facilitar futuras adaptações de produtos, imagens, informações da loja e formas de contato.

## Status
